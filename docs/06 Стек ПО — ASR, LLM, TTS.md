# 06 Стек ПО — ASR, LLM, TTS

← [[Джарвис — карта проекта]] · см. [[04 Архитектура v2 — реалистичная]]

Задача: **русский диалог за 0 ₽**. Ниже — что реально проверено и подходит.

---

## ASR (речь → текст)

| Вариант | Тип | Русский | Цена | Оценка |
|---|---|---|---|---|
| **Groq `whisper-large-v3-turbo`** ⭐ | облако | ✅ | Free: 20 RPM, **2000 RPD, 28 800 аудио-сек/день** (8 ч) | **Основной выбор.** Быстро (LPU), качественно |
| **Vosk `vosk-model-small-ru-0.22`** | локально | ✅ | Apache-2.0, 45 МБ | Резерв/офлайн. WER ~22–32 % — терпимо для команд |
| Vosk `vosk-model-ru-0.42` | локально | ✅ | Apache-2.0, **1,8 ГБ** | Точный (WER 4,5–19,5), но тяжёлый → только на сервере |
| **GigaAM v3** (Sber) | локально | ✅ SOTA | **MIT**, 220–600M параметров | Лучший русский, но нужен CPU/GPU и ~гигабайты RAM. Не для телефона |
| sherpa-onnx (ru) | локально | ⚠️ | Apache-2.0 | Есть ru-модели (порты Vosk). Рискованно под proot |
| SaluteSpeech (Сбер) | облако | ✅ | бесплатная квота | Альтернатива, если Groq недоступен |

**Решение v2:** Groq Whisper как основной, Vosk small-ru как офлайн-фолбэк.
**Решение v1 (в плане):** sherpa-onnx в Termux — вынесено из критического пути.

> Ключевой факт: **Whisper large-v3 хорошо знает русский.** Это снимает главный
> «красный» риск плана v1 («качество русского ASR неизвестно»).

## LLM (мозг)

| Вариант | Доступ из РФ | Цена | Оценка |
|---|---|---|---|
| **Ваш Cloudflare Worker → NVIDIA** ⭐ | ✅ проверено 27.09 | 0 ₽ | `nvidia/nemotron-3-super-120b-a12b` ответил за **1,35 с** |
| **Ваш Worker → OpenRouter** | ✅ проверено 27.09 | 0 ₽ (:free модели) | 458 моделей, 17 бесплатных |
| OpenRouter напрямую | ❌ 403 из РФ | — | Нужна обёртка |
| NVIDIA напрямую | ⚠️ блок меняется | — | 27.09 блок исчез, но нестабильно |
| Ollama локально | ✅ | 0 ₽ | Резерв; на ПК с GPU |
| GigaChat / Zhipu free | ⚠️ | 0 ₽ | Дополнительный резерв |

**Решение:** OpenAI-совместимый интерфейс (`base_url` + key + model) с 2–3 профилями
и автопереключением. Ваш Worker — первый профиль.

> ✅ Это самая зрелая часть проекта. **С неё и надо начинать** (Ступень 0).

## Кодовое слово (wake word)

| Вариант | Русский | Где работает | Оценка |
|---|---|---|---|
| ESP-SR **WakeNet** (в прошивке) | ❌ только cn/en | на ESP32-S3 | Штатные слова: `Hi ESP`, `Hi Lexin`, `你好小智` |
| ESP-SR **MultiNet** | ❌ только cn/en | S3/P4/S31 | До 300 команд, но не русский |
| **openWakeWord** ⭐ | ⚠️ англ., но есть модель **«hey jarvis»** | на ПК/сервере | **Решает проблему A3.** Wake word на хабе |
| microWakeWord | ⚠️ англ. | на ESP32 (ESPHome) | Для HA-ветки |
| Своя модель на русском | ✅ теоретически | — | Отдельный ML-проект, не для v1 |

**Решение v2:** в v1 — либо штатное слово из прошивки, либо **openWakeWord на хабе
с моделью «hey jarvis»** (что заодно оправдывает имя проекта). Русское кодовое слово —
цель на потом.

## Оркестраторы (что взять готового)

| Вариант | Лицензия | Плюсы | Минусы |
|---|---|---|---|
| **`xiaozhi-esp32-server`** | **MIT** ✅ (проверено 04.10) | ASR/LLM/TTS/VAD/3D-Speaker/MCP/память из коробки | Китайская документация, русского интерфейса нет, «не production-ready» |
| Свой Python-оркестратор | — | Полный контроль, минимум зависимостей | Писать самому (но это ~300 строк) |
| Home Assistant + Wyoming | HA: Apache-2.0 | Раздельные сервисы, зрелая экосистема, ru-модели | Тяжелее, свой мир |
| ESPHome voice_assistant | — | Простая прошивка, on-device wake word | Завязан на HA |

**Решение v2:** на Ступени 0–1 — **свой небольшой оркестратор** (полный контроль,
быстрый старт). На Ступени 2 — либо он же, либо `xiaozhi-esp32-server` (MIT),
если нужна готовая периферия (3D-Speaker, MCP-точка, память).

## Итоговый стек v2

```
Устройство : ESP32-S3 + xiaozhi-esp32 (MIT, ESP-IDF 6.1)
Транспорт  : WebSocket (LAN/хотспот 2,4 ГГц), аудио Opus
Оркестратор: Python (свой, ~300 строк) или xiaozhi-esp32-server (MIT)
VAD        : Silero VAD
ASR        : Groq whisper-large-v3-turbo  → фолбэк Vosk small-ru
LLM        : Cloudflare Worker → NVIDIA / OpenRouter (автопереключение)
TTS        : edge-tts ru-RU               → фолбэк Silero TTS
Голос      : 3D-Speaker (Г-18)
Память     : SQLite
Инструменты: MCP → Hermes на ПК
Хостинг    : ПК (дома) → Oracle Cloud Always Free (вне дома)
```
