## Шаг 1. Текстовый агент на ПК (1 вечер)

**Структура проекта:**

```
jarvis/
  .env                 JARVIS_LLM_BASE_URL, JARVIS_LLM_KEY, JARVIS_LLM_MODEL
  config.yaml          профили провайдеров, список фолбэков
  core/
    llm.py             OpenAI-совместимый клиент + автопереключение профилей
    memory.py          SQLite: история диалога
    orchestrator.py    сборка промпта, вызов LLM, стриминг
  tools/
    mcp_client.py      подключение MCP-инструментов
    hermes_tool.py     ask_hermes(вопрос) → запуск Hermes
  clients/
    cli.py             терминальный интерфейс  ← Шаг 1
    voice_pc.py        микрофон + динамики      ← Шаг 2
    ws_server.py       WebSocket для ESP32      ← Шаг 8
  requirements.txt
```

**Минимальный `llm.py` по смыслу:**

```python
# OpenAI-совместимо: работает и с NVIDIA через ваш Worker, и с OpenRouter, и с Ollama
from openai import OpenAI

class LLMRouter:
    def __init__(self, profiles):        # profiles из config.yaml
        self.profiles = profiles
    def chat(self, messages):
        for p in self.profiles:          # 1-й профиль, при 429/ошибке — следующий
            try:
                c = OpenAI(base_url=p["base_url"], api_key=p["api_key"])
                return c.chat.completions.create(
                    model=p["model"], messages=messages, stream=True)
            except Exception:
                continue
        raise RuntimeError("все профили недоступны")
```

**Критерий выхода:** вы задаёте вопрос в терминале и получаете ответ модели
**через ваш Cloudflare Worker**.

> Это самая низкорисковая часть: Worker + NVIDIA уже проверены живьём 27.09 (ответ за 1,35 с).

## Шаг 2. Голос на ПК (несколько вечеров)

Добавляем `voice_pc.py`:

```
микрофон (sounddevice) → Silero VAD → накопление фразы по тишине
        ↓
   Groq Whisper large-v3-turbo  (ASR, free 8 ч/день)
        ↓
   LLM через ваш Worker
        ↓
   edge-tts (ru-RU) → динамики ПК
```

**Обязательно:** стриминг на каждом шаге (LLM `stream=True`, TTS — потоковая выдача
по предложениям). Без стриминга Г-4 (≤4 с) не выполнить.

**Критерий выхода (это Г-2 и Г-3):** 10 коротких русских фраз — ≥8 распознаны верно;
ответ звучит вслух по-русски.

**План Б:** если Groq недоступен — Vosk `small-ru` локально (WER хуже, но работает офлайн).

## Шаг 3. Перебивание на ПК (1 вечер)

Механика (то, что делает ассистента «живым»):

1. Хаб держит **очередь реплик**, которые сейчас проигрываются.
2. VAD слушает **и во время проигрывания**.
3. Начали говорить → проигрывание останавливается, очередь обрезается.
4. Состояние «прервали после X, пользователь сказал Y» уходит в следующий промпт.

**Критерий выхода (Г-5):** вы говорите во время ответа — ассистент замолкает и слушает.
**План Б:** кнопка push-to-talk (ТЗ разрешает пожертвовать, приоритет 5).

## Шаг 5. Управление ПК через MCP (несколько вечеров)

```
Голос → LLM решает: нужен инструмент ask_hermes
      → MCP-клиент вызывает инструмент на ПК
      → на ПК запускается Hermes, возвращает результат
      → ассистент озвучивает
```

**Правила безопасности с самого начала (это Г-17…Г-19):**
- allow-list папок и команд; всё вне списка — отклоняется **до** выполнения;
- деструктивные операции — только с голосовым подтверждением;
- журнал каждого вызова (что, когда, по какой просьбе);
- начать только с **чтения и поиска**, команды — позже.

**Критерий выхода (Г-13…Г-15):** «найди файл с прошлой недели» — файл найден и назван.

> 🎯 **После шагов 1–5 у вас есть работающий голосовой ассистент «Джарвис»
> на русском, с перебиванием, кодовым словом и управлением ПК. Без паяльника и без покупок.**
> Это — то, что можно показать.

## Шаг 8. ESP32-S3 как спутник

1. Прошить `78/xiaozhi-esp32` (MIT) — сначала штатную сборку **`bread-compact-wifi`**,
   чтобы убедиться, что железо и аудиотракт живы (это M0 из плана v1 — правильный первый шаг).
2. Собрать свою board-конфигурацию по `docs/custom-board.md`: пины, OLED, WS2812, кнопка,
   адрес **своего** сервера. Учесть GPIO 33–37 (PSRAM) и strapping-пины.
3. Ассеты (шрифты, эмодзи, кодовое слово) — `78/xiaozhi-assets-generator`.
4. Подключить к своему оркестратору (WebSocket, Opus).
5. **Только теперь** — AFE/AEC для перебивания. Если не выйдет — остаётся push-to-talk.

**Критерий выхода:** устройство отвечает голосом через ваш сервер; работает от батареи.
