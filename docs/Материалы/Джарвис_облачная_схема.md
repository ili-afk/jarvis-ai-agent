# ☁️ Джарвис полностью в облаке — план

> Конфигурация: всё в облаке, работает откуда угодно, бюджет 0 ₽.
> Ответы пользователя: старт на облаке xiaozhi.me → потом свои провайдеры
> (NVIDIA / OpenRouter через Cloudflare Worker). Русский важен, английский тоже ок.
> Дата: 27.09.2026.

---

## 🎉 Главная новость: это работает, и почти ничего не нужно настраивать

Я нашёл то, что решает задачу целиком: **в облаке xiaozhi.me можно подставить свой
языковой сервер (LLM)**.

То есть можно:
- пользоваться **бесплатным облаком** xiaozhi.me — ноль настройки, ноль затрат;
- **и одновременно** пускать диалог через **свои ключи** NVIDIA / OpenRouter
  через ваш Cloudflare Worker.

**Перепрошивать устройство при этом не нужно** — меняются только настройки в консоли.

## 1. Как это устроено

```
┌────────────────────────────────────────────────┐
│  ДЖАРВИС (ESP32-S3) — работает где угодно       │
│  • кодовое слово — локально, на плате           │
│  • микрофон, динамик, экран                     │
│  • Wi-Fi → точка доступа телефона               │
└───────────────────┬────────────────────────────┘
                    │ WebSocket, аудио в Opus
                    ▼
┌────────────────────────────────────────────────┐
│  ОБЛАКО xiaozhi.me — БЕСПЛАТНО                  │
│  • распознавание речи (ASR)                     │
│  • синтез речи (TTS)                            │
│  • ведение диалога                              │
└───────────────────┬────────────────────────────┘
                    │ запрос к LLM по ВАШЕМУ адресу
                    ▼
┌────────────────────────────────────────────────┐
│  ВАШ CLOUDFLARE WORKER                          │
│  • ключи спрятаны внутри, наружу не уходят      │
└───────────────────┬────────────────────────────┘
                    ▼
        NVIDIA API  /  OpenRouter
```

### Что где работает

| Компонент | Где | Можно ли заменить |
|---|---|---|
| Кодовое слово | на плате | нет (работает всегда, без интернета) |
| **Распознавание речи (ASR)** | облако xiaozhi.me | ❌ **нет** — только встроенное |
| **Синтез речи (TTS)** | облако xiaozhi.me | ❌ **нет** — только встроенное |
| **Языковая модель (LLM)** | **ваш Worker** → NVIDIA/OpenRouter | ✅ **да** — своя |

**Ключевой вывод:** заменяется **только LLM**. Распознавание и синтез речи остаются
облачными и встроенными. Это одновременно и плюс (ничего не надо настраивать),
и главный риск (см. подводные камни).

## 2. ⚠️ Критичный подводный камень: точка доступа должна быть 2,4 ГГц

**Это самая частая причина, почему «не подключается вне дома».**

ESP32-S3 умеет работать **только в диапазоне 2,4 ГГц**. Он физически не видит сети 5 ГГц.

**А многие телефоны по умолчанию раздают точку доступа именно на 5 ГГц.** В результате
Джарвис просто не найдёт вашу сеть, и вы решите, что что-то сломано.

### Что сделать

В настройках точки доступа на телефоне:
- **Android:** Настройки → Точка доступа → Диапазон точки доступа → выбрать **2,4 ГГц**
- **iPhone:** Настройки → Режим модема → включить **«Максимальная совместимость»**
  (это переключает на 2,4 ГГц)

### Про «подключится сам»

Вы выбрали вариант: **точка доступа с тем же именем и паролем, что домашний Wi-Fi**.
Это работает — ESP32 подключается к сети по имени и паролю, и если они совпадают,
переподключение произойдёт автоматически, без ваших действий.

**Но:** обязательно выставьте **2,4 ГГц**, иначе трюк не сработает. И имя сети должно
совпадать **точно** — включая регистр букв.

## 3. Остальные подводные камни

| Риск | Насколько серьёзно | Что делать |
|---|---|---|
| **Русский язык в облаке** | 🔴 **Главный риск** | Проверить в первую очередь. Если распознавание русского плохое — нужен свой сервер (см. раздел 5) |
| **Нет интернета — нет Джарвиса** | 🟡 Ожидаемо | Это плата за «полностью облачно». Кодовое слово работает, но ответить он не сможет |
| **Расход мобильного трафика** | 🟢 Небольшой | Аудио сжимается в Opus. Один разговор — сотни килобайт, не гигабайты |
| **Аккаунт xiaozhi.me** | 🟡 Китайский сервис | Может потребоваться VPN для регистрации. Проверить заранее |
| **Задержка** | 🟡 | Путь: устройство → Китай → ваш Worker → NVIDIA. Может быть 2–4 секунды. Для диалога приемлемо, но не мгновенно |
| **Формат Base URL** | 🟡 | У разных серверов по-разному: где-то нужен `/v1`, где-то он дописывается сам. Проверить пробным запросом |

## 4. Этап 1 — что делать (пошагово)

### Шаг 1. Собрать железо
ESP32-S3 N16R8 + INMP441 + MAX98357A + OLED + динамик + аккумулятор + TP4056.
Как в нашем списке покупок, ничего не меняется.

### Шаг 2. Прошить
Официальная прошивка xiaozhi-esp32. Проще всего — через браузер на `web.esphome.io`.
Плату выбрать из готового списка (для S3 + INMP441 + MAX98357A + OLED есть готовая
конфигурация `bread-compact-wifi`).

### Шаг 3. Зарегистрироваться в облаке
Аккаунт на `xiaozhi.me`. Если не открывается — нужен VPN.
Подключить устройство к аккаунту.

### Шаг 4. Проверить базовую работу
Поговорить с Джарвисом на английском. Убедиться, что всё работает «из коробки».

### Шаг 5. 🔴 Проверить русский язык — самое важное
Попробовать говорить по-русски. Оценить:
- **распознавание** — понимает ли он вашу речь;
- **синтез** — внятно ли произносит ответы.

**Это решающий тест.** Если русский работает — вы в отличной ситуации, всё готово.
Если нет — переходите к разделу 5.

### Шаг 6. Подключить свой LLM
В консоли xiaozhi.me найти раздел **«Конфигурация большой модели»** и указать:

| Поле | Значение |
|---|---|
| Провайдер | **OpenAI-совместимый** (или «Custom») |
| **Base URL** | адрес вашего Worker, например `https://ваш-воркер.workers.dev/v1` |
| **API Key** | любой (воркер подставит свой настоящий ключ) |
| **Model ID** | например `nvidia/nemotron-3-super-120b-a12b` |

Сохранить. **Перепрошивать устройство не нужно.**

### Шаг 7. Проверить на улице
Включить точку доступа на телефоне (**2,4 ГГц**, имя и пароль как дома), выйти из дома
и поговорить с Джарвисом. Если работает — цель достигнута.

## 5. Этап 2 — если русский в облаке окажется плохим

Тогда единственный путь — **свой сервер** (`xiaozhi-esp32-server`), потому что там можно
подключить любое распознавание и синтез речи, включая русские.

Проблема: это хостинг, а бюджет 0 ₽. Но решение есть.

### 🎁 Oracle Cloud Always Free — бесплатно навсегда

| Параметр | Значение |
|---|---|
| Процессор | ARM, **4 ядра** |
| Память | **24 ГБ** |
| Диск | 200 ГБ |
| Срок | **бессрочно бесплатно** |
| Хватит ли | **с огромным запасом** |

Это лучший бесплатный вариант. Сервер с такими характеристиками потянет
`xiaozhi-esp32-server` вместе с локальным распознаванием речи (FunASR).

**Сложности:**
- при регистрации нужна банковская карта (для верификации, списаний нет);
- из РФ регистрация может потребовать VPN;
- бесплатные ARM-инстансы иногда «заняты» — иногда нужно подождать.

**Альтернативы**, если Oracle не подойдёт: Google Cloud (бесплатный e2-micro),
бесплатные тарифы Koyeb / Render / Fly.io. Но они слабее и с оговорками.

### Что даст свой сервер

| | Облако xiaozhi.me | Свой сервер |
|---|---|---|
| Стоимость | 0 ₽ | 0 ₽ (Oracle) |
| Настройка | 0 минут | Несколько часов |
| Русский ASR | ❓ под вопросом | ✅ **любой** (FunASR, облачные API) |
| Русский TTS | ❓ под вопросом | ✅ **любой** (EdgeTTS, Piper) |
| LLM | свой ✅ | свой ✅ |
| Работа без интернета | ❌ | ✅ (если сервер дома) |

## 6. Итог

**Ваша схема реализуема, и она проще, чем мы думали:**

1. **Начинайте с облака xiaozhi.me** — 0 ₽, ноль настройки, работает откуда угодно.
2. **Свой LLM подключается прямо в консоли** — ваши ключи NVIDIA/OpenRouter через
   Cloudflare Worker. Устройство перепрошивать не надо.
3. **Обязательно проверьте русский** — это единственный серьёзный риск.
4. **Точка доступа — строго 2,4 ГГц**, иначе не подключится.
5. **Если русский плохой** — Oracle Cloud Always Free даёт сервер 4 ядра / 24 ГБ
   бесплатно навсегда.

**Главное отличие от проекта из видео:** у автора был только облачный вариант и никакого
выбора. У вас — облако **плюс** свои модели, а при желании и свой сервер. При этом
сохраняется главное преимущество облака: устройство работает везде, где есть интернет.
