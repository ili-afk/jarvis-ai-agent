# 09 Риски и обходы

← [[Джарвис — карта проекта]]

Объединены риски из плана v1 + новые, найденные аудитом. Отсортировано по критичности.

---

## 🔴 Критические (ломают проект)

| Риск | Почему критично | Обход |
|---|---|---|
| **Русский ASR в Termux не заработает** | Это был единственный путь к Г-2 в плане v1 | Убрать Termux из критического пути: **Groq Whisper (free, 8 ч/день)**; Vosk small-ru как офлайн-резерв. См. [[04 Архитектура v2 — реалистичная]] |
| **Русское кодовое слово «Джарвис» на ESP32 невозможно** | Ф-3 — обязательное требование | Кодовое слово на хабе (**openWakeWord, модель «hey jarvis»**) или штатное слово прошивки. См. A3 в [[03 Аудит — что не так с планом v1]] |
| **Треугольник «0 ₽ + облако + вне дома» не сходится** | Без Г-8 теряется основная ценность | Зафиксировать основной путь (**Oracle Always Free**) и резервный (**Cloudflare Worker**) |
| **MCP-точка в бесплатной консоли xiaozhi.me может отсутствовать** | Вся схема «управление ПК без своего сервера» держится на ней | **Проверить до покупки железа.** Если нет — свой сервер |
| **Проект не доходит до кода** | Два месяца = 15 документов, 0 строк кода | Ступени 0–1 на ПК: результат за вечер, без железа |

## 🟠 Средние (замедляют, но обходимы)

| Риск | Обход |
|---|---|
| **AEC/перебивание не работает** в карманном корпусе | Не делать критерием выхода. План Б: push-to-talk. Разнести мик и динамик максимально |
| **Free-tier LLM (RPM/RPD) ломает Г-4** | 2–3 профиля с автопереключением; длинные задачи — на ПК-агент |
| **Android убивает Termux** (если всё-таки использовать) | `termux-wake-lock` + снятие оптимизации батареи + tmux + Termux:Boot |
| **Телефон не тянет VAD+ASR+стриминг** | Локально только VAD; ASR/LLM/TTS — облако |
| **TP4056 не даёт load-sharing** | Заменить на **IP5306** / модуль с power-path |
| **Эхо и обратная связь в корпусе** | Разнести мик и динамик; конденсатор по питанию усилителя; акустическая развязка |
| **Oracle из РФ: регистрация/карта/VPN** | Резерв — Worker-транспорт или платный дешёвый VPS |
| **Хотспот телефона на 5 ГГц** | ESP32-S3 видит только **2,4 ГГц**. Настроить диапазон; iPhone — «Максимальная совместимость» |
| **Приватность: голос и команды уходят третьей стороне** | Начать с бесплатных облаков только для ASR/TTS; команды ПК — только через свой сервер + локальное подтверждение |
| **Лицензия xiaozhi-esp32-server** | ✅ **Закрыт**: MIT (проверено 04.10.2026) |

## Риски, которых в плане v1 не было вовсе (найдены аудитом)

1. **Octal-PSRAM занимает GPIO 33–37** на N16R8 — конфликт с I2S/OLED при своей board-конфигурации.
2. **Strapping-пины** (0, 3, 45, 46) нельзя тянуть вниз при старте.
3. **INMP441 без AGC** — нужна калибровка усиления.
4. **Отсутствие аутентификации устройства** на сервере — Г-17/Г-19 обходятся кем угодно со знанием адреса.
5. **Бесплатные тарифы могут использовать данные для обучения** — конфликт с приватностью.
6. **Проект привязан к дедлайну 19 октября** (из чата 22.09), а плана «что показать» не было.
