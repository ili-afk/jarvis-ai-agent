# 01 Требования (ТЗ)

---

## Назначение

Персональный голосовой ассистент: карманное устройство, с которым говорят голосом,
и которое **выполняет действия на ПК** (файлы, программы, команды). Не собеседник,
а исполнитель.

**Ключевая идея:** устройство — только голосовой интерфейс; вся вычислительная работа
вне его. Устройство должно работать **автономно от места** (дома и вне дома).

---

## Ограничения

| Параметр | Значение |
|---|---|
| Страна | Россия (часть сервисов недоступна напрямую) |
| Пользователь | 10 класс; опыт: пайка, ESP32/Arduino, Python, API |
| Бюджет на облако | **0 ₽** — только бесплатные варианты |
| Бюджет на железо | 2 000–5 000 ₽ |
| Формат | Карманное, автономное питание |
| Язык | Русский (основной), английский — второй |
| Оборудование | Windows-ПК, Android-телефон, 3D-принтер |

**Архитектурное требование:** базовая работа не должна требовать постоянно включённого
домашнего ПК.

> 🔴 **Замечание аудита.** «0 ₽» + «полностью облачный» + «работает вне дома» —
> это треугольник, который не сходится без компромисса. Подробно — [[03 Аудит — что не так с планом v1]].

## Функциональные требования

### Обязательные (без них проекта нет)

| № | Требование |
|---|---|
| Ф-1 | Голосовой диалог (слышит, понимает, отвечает голосом) |
| Ф-2 | Активация по кодовому слову (без кнопок) |
| Ф-3 | **Своё** кодовое слово (например «Джарвис») |
| Ф-4 | **Прерывание ответа голосом** |
| Ф-5 | Русский язык |
| Ф-6 | Работа вне дома (через точку доступа телефона) |
| Ф-7 | Автономное питание, зарядка по USB |
| Ф-8 | Подключение своих языковых моделей |
| Ф-9 | Отсутствие обязательных платежей |

### Желательные (первая версия)
Ф-10 дисплей · Ф-11 световая индикация · Ф-12 свой корпус (3D-печать) ·
Ф-13 управление ПК · Ф-14 функционал уровня агента · Ф-15 память о разговорах

### Отложенные
Ф-16 второй дисплей · Ф-17 распознавание владельца · Ф-18 связь с телефоном ·
Ф-19 умный дом · Ф-20 камера

> 🔴 **Замечание аудита.** Ф-17 «отложено», но Г-18 (только владелец) — критерий
> второго этапа. Нельзя одновременно откладывать и требовать. В плане v1 это уже
> замечено и решено: перенести Ф-17 в первую версию (3D-Speaker в сервере уже есть).

## Критерии готовности

### Первая версия

| № | Критерий | Как проверяется |
|---|---|---|
| Г-1 | Активация по кодовому слову | Произнести — есть реакция индикацией |
| Г-2 | Русская речь распознаётся | 10 фраз → ≥8 верно |
| Г-3 | Ответ озвучивается по-русски | Разборчиво вслух |
| Г-4 | Задержка приемлема | Ответ ≤4 с от конца фразы |
| Г-5 | Ответ можно прервать | Говоришь во время ответа — замолкает |
| Г-6 | ≥2 ч от аккумулятора | Непрерывно |
| Г-7 | Зарядка по USB | От стандартного адаптера |
| Г-8 | Работа вне дома | Точка доступа телефона, без перенастройки |
| Г-9 | Своя языковая модель | Смена источника без перепрошивки |
| Г-10 | Нет обязательных платежей | 0 ₽/мес |
| Г-11 | Помещается в руке | Карманный формат |
| Г-12 | Индикация различима | Понятно без экрана |

### Второй этап (управление ПК)
Г-13 файловые операции · Г-14 запуск программ · Г-15 многошаговые задачи ·
Г-16 работа извне дома · Г-17 ограничение области · Г-18 только владелец · Г-19 журнал вызовов

### Общий критерий
Достать устройство из кармана в любом месте, сказать «Джарвис, …», получить голосовой
ответ, а при включённом ПК — ещё и выполнение задачи. Без ежемесячных платежей.

## Приоритеты при компромиссах

1. Голосовой диалог на русском — без этого проекта нет
2. Работа вне дома — иначе теряется ценность
3. Нулевая стоимость — жёсткое ограничение
4. Управление ПК — вторая цель
5. Остальное — по возможности

> ✅ Этот порядок — сильная сторона ТЗ: он прямо разрешает жертвовать перебиванием,
> вторым дисплеем и камерой. План v1 этим правом не пользуется. См.
> [[04 Архитектура v2 — реалистичная]].

## Чего в ТЗ не хватает (пробелы, найденные в планe v1 и подтверждённые аудитом)

1. **Г-2** — не заданы расстояние до микрофона, шум, число дикторов
2. **Г-4** — не сказано, сколько попыток и как считать (медиана/среднее)
3. **Г-6** — не задан режим (ожидание / диалог / постоянно активный Wi-Fi)
4. **Г-11** — нет числовых габаритов и массы
5. **Поведение при сбоях** — нет сети, лимит API исчерпан, сервер недоступен
6. **Аутентификация устройства на сервере** — иначе Г-17/Г-19 обходятся кем угодно, кто знает адрес
7. **Ф-17 против Г-18** — противоречие (см. выше)
8. **Г-16 против п. 2** — управление ПК требует включённого ПК; записать как условную функцию
9. **Приватность** — бесплатные тарифы часто разрешают использовать данные для обучения
