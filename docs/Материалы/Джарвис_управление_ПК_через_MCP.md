# 🤖 Джарвис как Hermes — управление ПК через облако

> Вопрос: сможет ли облачный Джарвис при подключении к ПК работать как Hermes?
> **Ответ: да.** Дата: 27.09.2026.

---

## ⚡ Короткий ответ

**Да, и для этого не нужен свой сервер.** Управление ПК делается через **MCP
(Model Context Protocol)** — тот самый протокол, о котором мы говорили с самого начала.

**Главная находка:** адрес для подключения своих инструментов (**«MCP-接入点»**, точка
подключения MCP) выдаётся **прямо в консоли xiaozhi.me**. То есть бесплатное облако
поддерживает подключение ваших инструментов — переходить на свой сервер не обязательно.

---

## 1. Как это работает

```
┌──────────────────────────────────────────────────────┐
│  ДЖАРВИС (ESP32) — где угодно, хоть на улице          │
└────────────────────┬─────────────────────────────────┘
                     ▼
┌──────────────────────────────────────────────────────┐
│  ОБЛАКО xiaozhi.me                                    │
│  ASR + TTS + LLM                                      │
│  + точка подключения MCP (адрес берётся в консоли)    │
└────────────────────┬─────────────────────────────────┘
                     │ WebSocket, соединение ИСХОДЯЩЕЕ
                     ▼
┌──────────────────────────────────────────────────────┐
│  ВАШ ПК — провайдер инструментов                      │
│  • подключается НАРУЖУ сам, публичный IP не нужен     │
│  • выполняет: файлы, команды, запуск программ         │
│  • может вызывать Hermes                              │
└──────────────────────────────────────────────────────┘
```

### 🔑 Два важных технических момента

**1. Провайдер инструментов на ПК подключается ИСХОДЯЩИМ соединением.**
Он сам «звонит» в облако по WebSocket. Значит **публичный IP, проброс портов и туннели
не нужны**. ПК просто должен быть включён и иметь интернет.

**2. Адрес точки подключения есть в официальной консоли.**
В документации прямо сказано: зайти в консоль **xiaozhi.me** и скопировать адрес точки
подключения текущего устройства. Свой сервер для этого не требуется.

---

## 2. Два пути реализации

### Путь А — готовые MCP-инструменты (быстрее, без кода)

Существуют готовые MCP-серверы для типовых задач:

| Инструмент | Что даёт |
|---|---|
| **Файловая система** | Читать, искать, создавать файлы в заданных папках |
| **Команды/терминал** | Выполнять команды на ПК |
| **Приложения** | Запускать программы |
| **Браузер** | Управлять браузером |

Вы регистрируете их на ПК, подключаете к точке — и Джарвис получает эти возможности.
**Писать код не нужно.**

### Путь Б — обернуть Hermes (это и есть «как Hermes и больше»)

Hermes — уже готовый агент, который умеет работать с файлами, кодом и командами.
Логично не дублировать его, а **завернуть в MCP-инструмент**.

**Идея:** вы пишете крошечный скрипт, который объявляет один инструмент — например
`ask_hermes(вопрос)`. Когда модель решает, что нужна агентская работа, она вызывает этот
инструмент, а скрипт просто запускает Hermes и возвращает его ответ.

**Схема работы:**

```
Вы: «Джарвис, найди файл с прошлой недели»
  ↓
LLM понимает: нужен инструмент ask_hermes
  ↓
Вызов ask_hermes("найди файл с прошлой недели")
  ↓
На ПК запускается: hermes chat -q "найди файл с прошлой недели" --cli -Q
  ↓
Hermes выполняет, возвращает результат
  ↓
Джарвис озвучивает ответ
```

**Почему это лучше, чем писать всё самому:** Hermes уже умеет то, что нужно — файлы,
код, команды, работу с провайдерами. Вы не переписываете его, а даёте ему **голос и уши**.

## 3. Что это даёт на практике

| Вы говорите | Что происходит |
|---|---|
| «Открой проект и запусти сборку» | Hermes выполняет на ПК |
| «Найди документ, который я правил вчера» | Hermes ищет по файлам |
| «Что у меня в папке загрузок?» | Читает и пересказывает |
| «Запусти проверку кода» | Выполняет команду |
| «Напиши скрипт для…» | Hermes пишет файл |

При этом Джарвис **остаётся облачным** — вы можете попросить его что-то сделать
из другого города, и ПК это выполнит.

## 4. ⚠️ Безопасность — обязательно прочитать

**Вы даёте голосовому ассистенту возможность выполнять команды на своём компьютере.
Это серьёзно.**

Риски:
- **Случайная команда.** Модель может неправильно понять просьбу и запустить не то.
- **Ошибка распознавания речи.** Джарвис может услышать не то, что вы сказали.
- **Любой рядом с колонкой** может отдать команду, если не настроено распознавание голоса.
- **Облако.** Команды проходят через чужие серверы.

### Что делать

1. **Ограничьте инструменты.** Не давайте доступ ко всему диску — только к нужным папкам.
2. **Исключите опасное.** Никаких удалений, форматирования, работы с системными папками.
3. **Включите распознавание владельца.** В экосистеме есть модуль **3D-Speaker** —
   Джарвис будет отзываться только на ваш голос. Это обязательная мера, если ПК под управлением.
4. **Логируйте.** Пусть все вызовы инструментов пишутся в файл — будете видеть, что он делал.
5. **Начните с безопасного.** Сначала только чтение и поиск. Команды — когда убедитесь, что работает.

## 5. Что это меняет в плане

**Ничего не ломается — план только дополняется.** Порядок остаётся:

| Этап | Что делаем | Что получаем |
|---|---|---|
| 1 | Облако xiaozhi.me + свои ключи | Голосовой ассистент, работает везде |
| 2 | 🔴 **Проверить русский язык** | Решающий тест |
| 3 | **Скопировать адрес MCP в консоли** | Готовность к подключению инструментов |
| 4 | **Подключить инструменты на ПК** | Управление ПК голосом |
| 5 | **Обернуть Hermes** | Полноценный агент с голосом |
| 6 | Распознавание владельца + ограничения | Безопасность |

**Важно:** шаги 3–5 не требуют своего сервера и не требуют денег. Бесплатное облако
xiaozhi.me даёт точку подключения MCP.

## 7. Итог

**Да, Джарвис сможет работать как Hermes.** Механизм для этого — MCP, и он уже встроен
в экосистему:

- **точка подключения MCP** выдаётся в консоли xiaozhi.me — свой сервер не нужен;
- **провайдер инструментов на ПК** подключается исходящим соединением — публичный IP не нужен;
- **Hermes оборачивается в один MCP-инструмент** — и получает голос, уши и лицо;
- **всё это на бесплатном облаке**, и работает откуда угодно.

По сути вы получаете то, что хотели с самого начала: **функционал Hermes и больше** —
только теперь у него есть голос, и он может работать, пока вы в другом городе.

**И не забыть про безопасность:** начать с чтения файлов, включить распознавание владельца,
ограничить папки.

⚠️ Схема основана на документации проекта xiaozhi и описаниях настройки MCP-точки

аккаунте. Если раздела MCP в бесплатной консоли не окажется, тот же результат достигается
своим сервером на Oracle Cloud (бесплатно навсегда).
