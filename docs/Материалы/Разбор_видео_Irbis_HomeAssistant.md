# 🎬 Разбор видео «ВЗЛОМАЛ колонку и заменил Алису» — и что это значит для Джарвиса

> Видео: `https://www.youtube.com/watch?v=KPLGcEE_cLg`
> «ВЗЛОМАЛ колонку и заменил Алису на своего ассистента: 5 лет на получение root и
> модификацию прошивки» — канал **man smart-home**, ~423 тыс. просмотров, ~октябрь 2025.
> Дата разбора: 27.09.2026.

---

## ⚡ Главное в двух абзацах

**Про колонку:** это **не** ваша Яндекс Станция Лайт. В видео — **Irbis A** (бюджетная
колонка с Алисой на чипе **Amlogic A113X**). Её удалось взломать, потому что чип известен,
а загрузчик не заблокирован. **К вашей Станции Лайт это не применимо** — там защищённая
загрузка (см. отдельный разбор).

**А вот что действительно важно:** автор использует **принципиально другой программный
стек** — **Home Assistant + Wyoming Satellite** вместо xiaozhi, о котором мы говорили.
И этот стек, возможно, **лучше подходит для Джарвиса**, чем наш текущий план. Ниже —
честное сравнение.

## 1. Что именно сделал автор

### Хронология (из глав видео)

| Время | Этап |
|---|---|
| 00:00 | О чём видео |
| 01:15 | **2020: получение root** |
| 08:00 | 2020: кастомизация прошивки |
| 10:53 | 2024–2025: YandexGPT, распознавание и синтез речи |
| 12:14 | **Установка Wyoming Satellite на колонку** |
| 18:33 | RGB-подсветка |
| 22:56 | Конечный результат |
| 24:32 | Что дальше |

Обратите внимание: в заголовке «5 лет», но root получен уже **в 2020 году** — то есть
примерно через год. Остальные четыре года ушли на доведение до рабочего состояния.

### Железо Irbis A

| Параметр | Значение |
|---|---|
| Процессор | **Amlogic A113X** — 4 ядра ARM Cortex-A53 |
| Оперативная память | **всего 128 МБ** |
| Хранилище | **128 МБ NAND** (файловая система UBIFS) |
| Wi-Fi/Bluetooth | модуль AP6212A |
| Микрофоны | **массив из 2 микрофонов**, 8-канальный захват |
| Динамик | моно |

**128 МБ оперативной памяти** — это очень мало. Но для Wyoming-спутника хватает, потому
что вся тяжёлая работа идёт на сервере, а спутник только передаёт звук.

### Использованные технологии (из описания)

- **Home Assistant + Wyoming Satellite** — основной стек
- Самописные интеграции для распознавания и синтеза речи
- **YandexGPT** — языковая модель
- **MPD** (Music Player Daemon) — музыка
- **Buildroot** — сборка системы

### Есть готовый гайд

Самое ценное: по этой колонке существует **полный открытый гайд** на GitHub —
`noname122021/irbis-a-mod-guide` (лицензия MIT). Там есть:
- инструкция по получению root через утилиту обновления Amlogic
- управление аудио (запись с массива микрофонов, воспроизведение)
- управление RGB-подсветкой и кнопками
- настройка Wi-Fi и Bluetooth
- модификация прошивки вручную (UBIFS)
- сборка Python и MPD через Buildroot
- раздел «извлечённые уроки» — ошибки и удачные решения

## 2. Почему Irbis A взломали, а вашу Станцию Лайт — нет

Это ключевой момент, чтобы не потратить время впустую.

| | **Irbis A** (из видео) | **Яндекс Станция Лайт** (ваша) |
|---|---|---|
| Процессор | Amlogic A113X — **известен** | **не опознан публично** |
| Загрузчик | Не заблокирован | **Secure boot / цепочка доверия** |
| Метод взлома | Утилита обновления Amlogic | Не существует |
| Документация | **Есть полный гайд** | Схемы нет, распиновки UART нет |
| Готовые модификации | Есть, сообщество | Нет |

**Вывод:** Irbis A повезло — у неё стандартный загрузчик Amlogic, который пускает
неподписанный код. Яндекс свою плату защитил. Поэтому «как в видео» с вашей Станцией
Лайт не получится.

**Но:** Irbis A продаётся б/у на Avito (55+ объявлений) за копейки. Её можно **купить
специально** как донора под этот проект. Это отдельный вариант — см. раздел 5.

## 3. Что такое Home Assistant + Wyoming (главное открытие)

Это архитектура голосового ассистента, принятая в Home Assistant — популярной открытой
платформе умного дома.

### Как устроено

| Роль | Что делает | Примеры железа |
|---|---|---|
| **Спутник** (satellite) | Ловит звук, определяет кодовое слово **на устройстве**, воспроизводит ответ | **ESP32-S3** (рекомендован официально), Raspberry Pi Zero 2 W, ReSpeaker |
| **Сервер** | Home Assistant OS + **Whisper** (распознавание речи) + **Piper** (синтез речи) + надстройка Wyoming | Raspberry Pi 5, мини-ПК, ваш ПК |

**Это ровно та архитектура, которую мы спроектировали** — устройство как терминал,
сервер как мозг. Только не наша самодельная, а зрелая, с огромным сообществом.

### Ключевые детали

- **ESP32-S3 — официально рекомендованное железо для спутника.** Есть эталонная плата
  **ESP32-S3-BOX-3**: двухмикрофонный массив, экран 2.4″, динамик, прошивается официальной
  прошивкой Home Assistant за ~5 минут через браузер.
- **microWakeWord** — определение кодового слова работает **на самом ESP32-S3** (на его
  нейросетевом ускорителе). До сервера доходит только команда после кодового слова.
- **Полностью локально** — Whisper и Piper работают на сервере, облако не нужно вообще.
- **Протокол Wyoming** передаёт аудиопоток от спутника к серверу.

## 4. Честное сравнение: наш план против Home Assistant

| Критерий | **xiaozhi** (наш план) | **Home Assistant + Wyoming** (из видео) |
|---|---|---|
| Назначение | Заточен под DIY AI-ассистента | Универсальная платформа умного дома с голосом |
| Русский язык | ⚠️ Слабо (облако проекта — китайский/английский) | ✅ **Хорошо** — Whisper знает русский, у Piper есть русские голоса |
| **Управление ПК** | ⚠️ Нужно писать MCP-инструменты самому | ✅ **Готово** — есть **HASS.Agent** для Windows |
| Экосистема интеграций | Небольшая | **Огромная** (тысячи интеграций: техника, медиа, датчики) |
| Эхо-подавление (перебивание) | ⚠️ Ограничено, device-side AEC только для отдельных плат | ✅ **Решается железом** — массивы ReSpeaker на XMOS дают аппаратный AEC и надёжное перебивание |
| Сложность настройки | Проще | Сложнее, есть кривая обучения |
| Требования к серверу | Лёгкие | **Тяжёлые** — Whisper требует нормального процессора |
| Локальные модели | ✅ Ollama | ✅ Есть агент диалога + можно подключить любой OpenAI-совместимый API |
| Облачные модели | ✅ Через ваш Cloudflare Worker | ✅ **Тоже** — ваш Worker подойдёт без изменений |

### Три вывода из таблицы

1. **По русскому языку Home Assistant сильно выигрывает.** Whisper — одна из лучших
   открытых моделей распознавания, и русский у неё в числе основных. Это снимает главную
   проблему нашего плана.

2. **Управление ПК уже решено.** **HASS.Agent** — это готовый клиент для Windows, который
   позволяет отправлять команды из Home Assistant на компьютер, получать уведомления,
   запускать приложения. То есть «Джарвис, открой проект» работает без написания
   MCP-инструментов с нуля.

3. **Проблема перебивания решается покупкой правильного микрофона.** Массивы
   **ReSpeaker на чипе XMOS** имеют **аппаратное эхо-подавление** — по описанию
   обеспечивают «надёжное перебивание, пока играет музыка». Это ровно то, что мы
   не могли решить на ESP32 программно.

## 5. Три варианта — что выбрать

### Вариант A — сменить стек на Home Assistant + Wyoming

**Что делать:** ESP32-S3 (или готовая ESP32-S3-BOX-3) как спутник + Home Assistant
на сервере + Whisper/Piper.

**Плюсы:** русский язык, готовое управление ПК, огромная экосистема, аппаратное
перебивание с правильным микрофоном.

**Минусы:** нужен более мощный сервер; сложнее настройка; BOX-3 это «шайба», а не
карманное устройство.

### Вариант B — купить б/у Irbis A и повторить проект из видео

**Что делать:** купить колонку на Avito (б/у, недорого), пройти по гайду
`irbis-a-mod-guide`, получить готовое устройство с корпусом, массивом микрофонов,
динамиком и RGB.

**Плюсы:** **вы получаете готовое железо целиком** — корпус, 2 микрофона, динамик,
подсветка. Ничего не надо печатать и паять. Есть пошаговый гайд.

**Минусы:** всего **128 МБ RAM** и 128 МБ памяти — впритык; процесс прошивки Amlogic
рискованный; устройство не карманное, а настольное.

### Вариант C — остаться на xiaozhi

**Что делать:** наш исходный план на ESP32-S3 + xiaozhi-esp32-server.

**Плюсы:** проще, легче сервер, готовая конфигурация платы ровно под наш набор деталей,
проект заточен именно под такое устройство.

**Минусы:** русский язык слабее; управление ПК надо писать самому; экосистема меньше.

## 6. Что я рекомендую

**Смешать подходы, а не выбирать один.** Вот оптимальная схема:

1. **Железо — как мы планировали:** ESP32-S3 N16R8 + INMP441 + MAX98357A + OLED.
   Ничего не меняется, детали те же.

2. **Сервер — Home Assistant, а не xiaozhi.** Причина: русский язык, готовое управление
   ПК через HASS.Agent, экосистема. Whisper и Piper дают качественный русский голос.

3. **Прошивка спутника — официальная HA voice firmware** для ESP32-S3 вместо xiaozhi.
   Она официально поддерживает ESP32-S3 и умеет microWakeWord.

4. **Если хочется максимального качества перебивания** — позже добавить микрофонный
   массив ReSpeaker с аппаратным AEC. Это решает проблему, которую мы считали
   непреодолимой на ESP32.

5. **Ваш Cloudflare Worker остаётся нужным** — Home Assistant подключает облачные
   модели через OpenAI-совместимый API, а Worker даёт именно такой адрес.

**Почему не вариант B:** прошивка Amlogic — рискованная операция с реальным шансом
окирпичить устройство, а 128 МБ памяти не оставляют запаса. Для первого проекта это
лишний риск. Но если найдёте колонку совсем дёшево и захотите эксперимент — гайд готов.

## 7. Что нужно проверить перед сменой плана

Прежде чем менять стек, надо честно ответить на три вопроса. Я могу исследовать
каждый, если скажете.

1. **Потянет ли ваш ПК Whisper?** Whisper требователен к процессору. Если ПК слабый —
   распознавание будет медленным, и это убьёт весь эффект. Надо проверить вашу
   конфигурацию.

2. **Как запустить Home Assistant на Windows?** Официально рекомендуется HA OS на
   отдельном устройстве. Есть вариант в Docker, но на Windows он не самый гладкий.
   Нужно понять, что реалистично именно у вас.

3. **Насколько сложна настройка HA для новичка?** Home Assistant мощный, но у него
   есть кривая обучения. Стоит оценить, не утонете ли вы в настройке вместо сборки
   устройства.
