# Джарвис (Jarvis) — карманный голосовой AI-ассистент

> **EN:** Jarvis is a personal voice AI assistant — a small, battery-powered **ESP32-S3**
> satellite that speaks **Russian** and can execute tasks on a PC. Cloud budget: **0 ₽/month**.
> Hardware budget: **2 000–5 000 ₽**. Architecture: *hub + satellite* (like Alexa / Alice /
> Home Assistant) with an OpenAI-compatible **cloud brain**.

Джарвис — персональный голосовой ассистент, который умеет не только разговаривать по-русски,
но и **выполнять задачи на ПК**. Это не «умная колонка» и не чат-бот: это связка
«дешёвый спутник + внешний мозг», спроектированная под реальные ограничения —
нулевой бюджет на облако, работа вне дома, автономное питание.

---

## Ключевая идея

Устройство остаётся **тонким** (микрофон, динамик, кнопка, индикация), а весь «ум» живёт
снаружи — в облачном OpenAI-совместимом endpoint и/или на домашнем ПК. Это снимает главное
ограничение: локальную LLM невозможно запустить на микроконтроллере.

```
   ┌─────────────┐   Wi-Fi/WS   ┌──────────────────────────────┐
   │  СПУТНИК     │ ───────────▶ │  ХАБ / ОБЛАЧНЫЙ МОЗГ          │
   │  ESP32-S3    │              │  wake word → ASR → LLM → TTS  │
   │  N16R8       │ ◀─────────── │  + инструменты (MCP)          │
   │  mic/spk/LED │   Opus/audio │  + память диалога             │
   └─────────────┘              └──────────────────────────────┘
                                          │
                                          ▼
                                   управление ПК (файлы,
                                   запуск программ, MCP)
```

## Архитектура и стек

| Слой | Решение | Где |
|---|---|---|
| Wake word | openWakeWord на хабе (готовое «hey jarvis») | хаб |
| VAD / barge-in | Silero VAD; план Б — push-to-talk | хаб |
| ASR (рус.) | GigaAM v3 (MIT), Vosk, Groq `whisper-large-v3-turbo` (free) | хаб / облако |
| LLM | свой OpenAI-совместимый источник (2–3 профиля с автопереключением) | облако / ПК |
| TTS (рус.) | edge-tts (бесплатно), Silero, Piper | хаб / облако |
| Инструменты | MCP (управление ПК, файлы, запуск программ) | хаб + ПК |
| Память | краткосрочная + долговременная (SQLite) | хаб |
| Прошивка | `xiaozhi-esp32` (MIT), своя board-конфигурация | спутник |

## Железо

- **ESP32-S3 N16R8** (8 МБ PSRAM обязательны для AFE/AEC)
- Донор: корпус, динамик 4 Ω 5 Вт, БП от «Яндекс Станция Лайт»
- Аккумулятор + модуль с power-path (IP5306)
- Корпус — 3D-печать
- Бюджет: **2 000–5 000 ₽**

## Дорожная карта

1. **Диалог** — голосовой цикл «кодовое слово → ответ» на столе.
2. **Корпус и питание** — автономная сборка, индикация.
3. **Инструменты** — управление ПК через MCP.
4. **Вне дома** — работа через хотспот телефона, удалённый доступ.

Каждый этап заканчивается **работающим результатом**.
