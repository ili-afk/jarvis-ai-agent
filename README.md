# Джарвис — мой карманный голосовой ассистент

Привет. Меня зовут **Илья**, мне **16**, я из Москвы.

Это **Джарвис** — маленький голосовой ассистент, который я делаю сам. Он должен влезать в карман,
работать от батарейки и отвечать по-русски. Не «умная колонка» за 10 тысяч, а моя вещь, которую
я собрал своими руками и которая понимает меня по имени.

> Здесь лежит вся моя работа по проекту: требования, архитектура, разбор аналогов и честный
> список того, что уже получилось, а что нет.

---

## Зачем он мне

Я хотел ассистента, который:
- понимает **русский** (не «привет, я не расслышал», а нормально);
- реагирует на **своё кодовое слово** — «Джарвис»;
- работает **вне дома**, через интернет с телефона;
- **ничего не стоит** каждый месяц (я школьник, у меня нет бюджета на подписки);
- умеет **управлять моим ПК** голосом.

И самое главное — его собираю **я**, а не покупаю готовый.

---

## Почему на ESP32

ESP32-S3 — микроконтроллер за ~700–900 рублей. Он крошечный, жрёт мало, влезает в корпус от
старой колонки. Всё «умное» (распознавание речи, модель) живёт в облаке, а плата — это уши, рот
и кнопки. Так даже дешёвое железо может быть ассистентом.

Вот только есть засада, о которой я узнал уже в процессе: **русских моделей для кодового слова
не существует**. То есть научить ESP32 слышать именно «Джарвис» — нельзя. Это одна из причин,
почему проект застрял и позже превратился в [BIMO](https://github.com/ili-afk/bimo-pi5-agent)
(домашний агент на полноценном Linux).

## Как он устроен

```
   микрофон → [ ESP32-S3 ] → Wi-Fi → облако (распознавание → модель → голос) → динамик
                    │
                    └→ кнопки, светодиодная индикация, 3D-печатный корпус
```

Идея: **дешёвый спутник + умный мозг в облаке**. Плата ничего тяжёлого не считает — только
слушает, отправляет и говорит.

| Слой | Чем |
|---|---|
| Кодовое слово | openWakeWord на «умной» стороне (или кнопка) |
| Распознавание речи | Groq Whisper (бесплатно) / локальный Vosk |
| Модель | свой OpenAI-совместимый источник (Cloudflare Worker) |
| Синтез голоса | edge-tts / Silero / Piper |
| Управление ПК | MCP |

## Ограничения

- Кодовое слово «Джарвис» на самой плате невозможно (нет русских моделей) — только на «умной» стороне.
- Перебивание голосом в маленьком корпусе — акустически тяжело, поэтому план Б — кнопка.
- Без интернета он не работает вообще.
